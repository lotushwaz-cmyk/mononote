# 모노 노트

캘린더 · 일기 · 아카이브를 한곳에 담은 개인용 안드로이드 앱입니다.
흑백 톤, 얇은 외곽선 박스, 고딕 글꼴(휴대폰 기본 고딕)로 만들었어요.

## 휴대폰에 설치하는 방법

1. **Android Studio 설치** — https://developer.android.com/studio 에서 받아 설치합니다 (무료).
2. 이 폴더(`MonoNote`)의 압축을 풀고, Android Studio에서 **Open** → `MonoNote` 폴더를 선택합니다.
   - 처음 열 때 필요한 도구를 자동으로 내려받느라 몇 분 걸려요. 아래쪽 진행 막대가 끝날 때까지 기다리세요.
3. 휴대폰 준비
   - 설정 › 휴대전화 정보 › 소프트웨어 정보 › **빌드번호를 7번 탭** → 개발자 모드가 켜집니다.
   - 설정 › 개발자 옵션 › **USB 디버깅** 켜기
   - USB 케이블로 컴퓨터와 연결하고, 휴대폰에 뜨는 "USB 디버깅 허용"을 누릅니다.
4. Android Studio 위쪽에 내 휴대폰 이름이 보이면 **▶ (Run)** 버튼을 누릅니다. 휴대폰에 "모노 노트"가 설치되고 실행돼요.

> 설치 파일(APK)만 따로 만들고 싶으면: 메뉴 **Build › Build App Bundle(s) / APK(s) › Build APK(s)** → 완료 알림의 *locate* 를 누르면 `app-debug.apk` 가 있어요. 이 파일을 휴대폰으로 옮겨 설치할 수 있습니다.

## 기능

### 캘린더
- **월간**: 큰 월 숫자 헤더, 음력 표시 스위치(달력 칸마다 음력 날짜), 일정은 카테고리 색 막대로 표시
  - 달력을 좌우로 밀면 이전/다음 달, 월 숫자를 누르면 날짜로 바로 이동
  - 날짜를 한 번 누르면 선택, 한 번 더 누르면 일간 화면
- **일간(타임테이블)**: 주간 막대 + 시간 축 타임라인, 지금 시각 빨간 선, 겹치는 일정은 나란히 배치
  - 빈 시간을 누르면 그 시각에 일정 추가
- **카테고리**: 이름·색 자유롭게 추가/수정/삭제 (월간 화면 카테고리 줄의 ‘편집’)
- **반복**: 안 함 / 매일 / 매주(요일 선택) / 매월 / 매년 / 매년(음력), 반복 종료 날짜, 반복 중 하루만 삭제

### 일기
- 맨 위에 날짜, 아래에 내용. 탭하면 쓰기, ‘완료’로 끝내기
- **꾹 누른 채 오른쪽으로 밀면** 검정 종이로 덮이고 그 위에 새로 쓸 수 있어요 (원래 글은 지워지지 않고 가려짐)
- **꾹 누른 채 왼쪽으로 밀면** 아래에 있던 글이 다시 보여요. 여러 겹으로 계속 덮을 수 있어요

### 아카이브
- 영화 · 드라마 · 예능 · 음악 · 책 감상 기록
- 왼쪽 이미지(갤러리에서 선택), 오른쪽 제목 · 감상 날짜 · 별점 5개
- 종류별 필터, 제목 검색

### 백업
1. **구글 계정 자동 백업** — 휴대폰의 구글 백업이 켜져 있으면 자동으로 백업되고, 새 휴대폰에 앱을 설치하면 자동 복원돼요 (25MB까지).
2. **백업 파일** — 설정(달력 화면 오른쪽 위 아이콘) › 백업 파일 만들기 / 불러오기.
   일정·일기(덮어 쓴 글 포함)·아카이브·사진이 파일 하나(`.mnbak`)로 저장돼요. 비밀번호를 넣으면 AES-256으로 암호화됩니다.

## 참고
- 음력은 안드로이드에 내장된 음력 계산을 써요. 한국 음력과 아주 드물게 하루 차이가 날 수 있어요.
- 공휴일 표시는 아직 없어요 (일요일만 빨간색).
- 모든 데이터는 휴대폰 안에만 저장돼요. 앱을 지우면 데이터도 지워지니 백업 파일을 꼭 만들어 두세요.
- 앱 이름은 `app/src/main/res/values/strings.xml` 의 `app_name` 에서 바꿀 수 있어요.

## 코드 구조
```
app/src/main/java/com/mononote/app/
├─ data/      Models(데이터 모양), AppStore(저장), DateUtils(음력·반복), Backup(백업 파일·암호화)
└─ ui/        Theme, Icons, Components(공통 부품), AppRoot(하단 탭)
   ├─ calendar/  월간·일간·일정 편집·카테고리
   ├─ diary/     밀어서 덮는 일기
   ├─ archive/   감상 기록
   └─ settings/  백업 설정
```
